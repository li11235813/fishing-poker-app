# 钓鱼扑克

一个支持两名玩家通过四位房间码联机的网页小游戏。

## 已实现
- 首页创建房间 / 输入四位码加入房间
- 房主点击开始后进入对局
- 双浏览器按同一房间码同步状态
- 30 秒超时切换
- A=1，J=11，Q=12，K=13
- 仅允许“手牌 1 张 + 公共区若干张 = 14”收牌
- 游戏结束后按花色积分判胜负

## 当前限制
- 房间状态保存在服务端内存，服务重启后房间会消失
- 暂未做断线重连身份恢复
- 暂未做公网正式部署配置文件

## 本地运行
先开前端开发服务器：
```bash
npm install
npm run dev
```

再开房间服务：
```bash
npm run dev:server
```

前端默认在 `http://localhost:5173`，会代理 `/api` 到 `http://localhost:5174`。

## 生产启动
先构建：
```bash
npm run build
```

再启动：
```bash
npm start
```

启动后，Express 会同时提供：
- `/api/*` 房间接口
- `dist/` 里的前端页面

默认端口：`5174`，可通过 `PORT` 环境变量覆盖。

## 适合下一步部署的方式
- 单机 / VPS：直接 `npm run build` 后 `npm start`
- Railway / Render / Fly.io：使用同样的生产启动方式
- 如果要更稳定房间数据，再把内存房间改成 Redis / 数据库
